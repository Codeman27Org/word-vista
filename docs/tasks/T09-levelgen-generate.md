# T09 — Level generator: validate & generate 600 levels

**Goal:** a validator, the generator CLI, and the 600 committed levels in `public/levels/`.
**Read first:** `docs/05-level-generator.md` (§Generation procedure, §Validation); `docs/04-data-contracts.md` (index/pack JSON).
**Depends on:** T08.

- generated by running the CLI: `public/levels/index.json`, `public/levels/pack-001.json` … `pack-040.json`

## Spec

### `validate.ts`
```ts
export function validateLevel(level: Level): string[];
export function validateAll(rootDir: string): string[]; // reads public/levels/index.json and all packs under rootDir
```
Implement the 8 checks in docs/05 §Validation. Error strings must include the level id, e.g. `"level 12: accidental run 'PLA' at row 3"`.
It must also work as a CLI. Put this at the bottom:
```ts
import { pathToFileURL } from "node:url";
if (process.argv[1] && import.meta.url === pathToFileURL(process.argv[1]).href) {
  const errors = validateAll(process.cwd());
  if (errors.length > 0) {
    console.error(errors.slice(0, 50).join("\n"));
    console.error(`${errors.length} error(s)`);
    process.exit(1);
  }
  console.log("OK — all levels valid");
}
```
(Move the `import` to the top of the file with the other imports.)

### `generate.ts`
CLI only. Implement docs/05 §Generation procedure exactly:
- `createRng(SEED)`; per-tier shuffled base list (cached); `usedKeys` across all levels.
- Write files with `mkdirSync(dir, { recursive: true })` and `writeFileSync(path, JSON.stringify(data) + "\n")`.
- Pack file names: `pack-${String(k).padStart(3, "0")}.json`; `file` field = `levels/pack-001.json`.
- At the end call `validateAll(process.cwd())` and exit 1 if there are errors.
- Print one summary line per tier: `levels 1-10: words min/median/max = 3/4/4, bonus median = 6`.

### Run it
```
npm run levels
npm run validate-levels
```
Expect roughly: tier medians of grid words ≈ 4, 6, 8, 10, 12. Runtime well under a minute.

## Tests
`tests/levelgen/validate.test.ts` (use `LEVEL12` fixture; clone with `structuredClone` before changing):
- `validateLevel(LEVEL12)` → `[]`.
- Move `ATE` to `{ row: 5, col: 2 }` → errors (conflict/accidental run).
- Put a grid word into `bonus` → error.
- Add a word `{ word: "NET", row: 0, col: 0, dir: "across" }` → errors (letter conflict, disconnected or accidental run).
- Change `letters` to 5 letters → error (words[0] must use all letters).

`tests/levels.test.ts` (reads the generated files with `readFileSync`):
- index has 40 packs and `totalLevels === 600`.
- Level ids across packs are exactly 1..600 in order; each level's `packId` matches its pack.
- `validateLevel` returns `[]` for every level.
- Each level's `letters.length` equals `TIERS` wheel size for its id, and `words.length` is within `[minWords, maxWords]`.
- No two levels share the same `lettersKey`.

Also add a layout property test to `tests/levelgen/layout.test.ts`: for 20 seeds, build a layout for `"GARDEN"` with its candidates (from `loadWordLists`), wrap it in a fake `Level`, and assert `validateLevel` → `[]` (pass `bonus: []`).
